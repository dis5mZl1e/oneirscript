# 梦层 / Oneirscript

[主页](README.md) · **简体中文** · [English](README_EN.md)

*在梦里，文字可以被篡改，环境可以被利用，离开的路需要自己找到。*

梦层是一款以潜意识为舞台的单人回合制 Roguelike，使用 Python 与 Textual 构建。探索程序生成的梦境，组合装备语句，篡改描述现实的文字，并利用液体、气体和材料反应应对危机。

## 玩法

- **回合制探索**：观察环境、选择路线，在行动与资源消耗之间作出取舍。
- **语法装备**：通过条件、目标、位置与行为组合构筑。
- **现实篡改**：修改描述对象和环境的语句，同时承担资源代价与风险。
- **环境互动**：利用液体、气体、燃烧与传导等材料反应处理危机。
- **梦境下潜**：探索主梦与支线梦境，面对更深处的异象和终局选择。

## 从源码运行

需要 **Python 3.11 或更新版本**。下载或克隆仓库后，在仓库根目录执行：

```sh
python -m pip install -r requirements.txt
python run_demo.py
```

首次启动推荐的 WezTerm 终端可能需要联网下载。也可直接使用当前终端：

```sh
python run_demo.py --compat-terminal
```

游戏内设置支持中文／英文切换。`game_config.ini` 提供启动配置，存档保存在本地 `save/`。

## 基础操作

| 按键 | 操作 |
|---|---|
| WASD / 方向键 | 移动 |
| X | 观察 |
| Enter | 行动与确认 |
| Tab | 行囊 |
| N / B | 下潜／回溯 |
| Esc | 取消与暂停 |
| F10 | 保存并退出 |

完整操作以游戏内键位说明为准。
