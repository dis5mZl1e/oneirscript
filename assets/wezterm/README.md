# 梦层专用窗口效果

`dream_effects.lua` 只由游戏的独立 WezTerm 配置加载，不是个人全局配置。

- Ctrl+Shift+Space：效果菜单；也可 Ctrl+Shift+右键打开，用鼠标点选。
- Ctrl+Shift+M：梦境氛围 → 清晰阅读 → 静态，循环切换。
- 菜单另有靛青、苔绿、余烬配色、微光脉冲和全屏切换。
- 清晰阅读和静态模式不播放动画，也不响应焦点/BEL 的运动效果。
- 模式/配色按窗口保存，配置重载后保留；新窗口仍默认梦境氛围。
- 普通游戏点击、滚轮、右键及 F1–F12 没有被新增绑定占用。

纹理由 `scripts/build_wezterm_textures.py` 通过确定性数学函数生成，无第三方图片。
两张 256×128、64 帧 APNG 由 WezTerm 原生播放；静态图为独立阶梯渐变。
采用代码库相同许可。终端脚本不会改游戏伤害、回合、输入或存档。

2026-10-17：背景改为像素风。源画布 64×32，八色阶与固定有序抖色，
按最近邻放大至 256×128。雾层与流光保留动画，静态图改为独立的阶梯渐变。
Lua 不再叠连续 Gradient；以固定整数尺度镜像铺贴，避免随窗口百分比任意拉伸。
静态模式只保留底色和阶梯图，清晰阅读仅底色。主页字符门景同样使用方块色带。
