# Web 0.1.1 更新日志

## 网页前端重设计：暗色梦境档案

- 用深墨纸本、细线分区和克制的类型色替换玻璃圆角，统一主页、游戏工作区与浮窗。
- 状态改为紧凑的三列资源读数；调整导航、地图与正文比例，适配桌面和窄屏。
- 桌面行囊详情与格子独立滚动，详情正文滚动时保留操作按钮，减少筛选和说明占高。
- 构想改为卡片与详情分区；发射卡片分别呈现标题、数值、弹匣、不可用原因与操作。
- 日志改为时间线，任务改为目标和进度卡片，个人数值分组展示；整理联想盘、篡改、图鉴和设置的阅读层次。
- 宽屏主页将入梦与存档分列。

> 发布说明：桌面版 0.1.1 已于 2026-11-01 发行（Windows / Linux / macOS 中英 8 包，另附源码包与校验清单）；网页前端源码由开发仓库维护，本桌面源码仓库不包含网页端；本次未单独制作网页发行包。桌面发行见 [v0.1.1 Release](https://github.com/dis5mZl1e/oneirscript/releases/tag/v0.1.1)。

## 本轮桌面内容同步

- 行囊新增默认五列格子与竖排列表切换，支持滚动、点击使用；使用后保留行囊页。大图标使用字体轮廓绘制，数量和装备星标独立叠放。
- 格子按物品类型填色、稀有度描边，增加折痕装裱角和木色选框；物品详情移至上方，介绍采用衬线字体并可展开收起。
- 构想新增类型底色及类型效果说明，卡片正文只选择，释放按钮或 Enter 执行。
- 发射源显示数值与弹匣余量，支持手动换弹、记住选源、空弹匣再次瞄准时分步装填，以及消耗来源耗尽后顺序切换。
- 气体按三档点阵密度显示，液体图案贴底；移除墙边彩线，补齐植物和物品字体，PUA 风格默认开启。
- 设置新增行囊边框、图标风格及字符风格；普通新档加入六步入梦介绍，可在数据设置重看，篡改编辑器加入玩法说明。
- 新增实际伤害数字：区分受击、击破与格挡，只显示可见范围内的结算结果；重绘不重复，减少动态效果时显示静态数字。

本次更新主要移植桌面端的地图表现与交互，并重新整理网页界面。

## 地图与画面

- 新增图像地图，并设为默认显示模式；可在设置中切换，保留已有的手动选择。
- 引入桌面端地形分层与高度表现，修正地板、生物、物品及角标之间的遮挡和错位。
- 加入主角周围的光照与桌面字符施法动画，让战斗反馈更清晰。
- 统一地图字形、地板点、主角形象及图标字体，修复部分特殊符号显示异常。
- 移除多余的踩踏、液体和气体粒子效果，材质仅保留轻微抖动。

## 界面与操作

- 重新规划左右面板与悬浮窗布局，改善文字裁切、二级菜单溢出和缩放适配。
- 为不同标签页和功能区域增加独立配色，结合磨砂玻璃背景、底纹及按钮交互反馈。
- 统一字段颜色，并对齐三条属性条的标签、条形与数值。
- 篡改界面改为分区编辑，区分目标、槽位、候选项、预览、消耗与风险；右侧面板可直接操作，并可移至悬浮窗继续编辑。
- 篡改使用大悬浮窗，仅联想盘保留全屏；各类悬浮窗支持拖拽。
- 提高地图左侧提示的透明度，增加事件栏高度，移除左下角“左键行动”提示。
- 优化方向键连按节奏，减少输入积压导致的集中跳步。
- 点击主角所在格不再打开地形界面；保留独立查看入口和原有拾取、交互操作。

## 图鉴、联想盘与文本

- 补全网页图鉴入口，支持分类、搜索与详情查看。
- 联想盘装备改用桌面端图案表示，替代首字缩写；放大底部操作按钮。
- 接入桌面端的句子符号表示，并保留完整原文查看。
- 英文层名改为完整名称，取消符号缩写。
- 修复行囊物品前的图标显示错误。

## 性能与兼容

- 缓存材质纹理，减少重复绘制和无变化的界面重建。
- 字符动画短暂播放后停止，避免增加常驻动画循环。
- 同步网页发布包与本地 HTML，改善中英文字体及特殊字形加载。
